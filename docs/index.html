Interactive setup

Shared memory for Grok, Claude, and other harnesses. One Postgres brain. Click your path, copy each command, check off steps.

1 Install the CLI

brew tap Pzharyuk/tools
brew update
brew untap Pzharyuk/tools
brew tap Pzharyuk/tools
brew install harness-memory

If Homebrew complains about checksums: brew cleanup -s harness-memory && brew install harness-memory

2 Point at the cluster

Must be on church office IP 97.120.177.5. Home is denied at Cloudflare Access.

export MEMORY_URL=https://memory.onit.systems

Do not run brew services start postgresql@16 or brew services start harness-memory.

2 Start local Postgres + memoryd

brew services start postgresql@16
createdb memory
brew services start harness-memory

Listens on http://127.0.0.1:8741.

3 Mint tokens

memory token create prints MEMORY_TOKEN is required until you run memory init and export the admin token.

memory init
export MEMORY_TOKEN='<paste admin token>'
memory token create --harness grok
memory token create --harness claude

If init returns 409, admin already exists — reuse the saved admin token. Plugin gets the harness token, not admin.

4 Install the Grok plugin

Not on the Plugins tab until installed. Marketplace source is ai-claude-plugins, not xAI Official. Refresh first.

grok plugin marketplace add Pzharyuk/ai-claude-plugins
grok plugin marketplace update ai-claude-plugins
grok plugin install harness-memory --trust

When prompted:

MEMORY_URL=https://memory.onit.systems
MEMORY_TOKEN=<grok token from step 3>

Local: leave MEMORY_URL as http://127.0.0.1:8741.

4 Install the Claude plugin

/plugin marketplace add Pzharyuk/ai-claude-plugins
/plugin install harness-memory@ai-claude-plugins

If it still does not list, Marketplace tab r, or:

git -C ~/.claude/plugins/marketplaces/ai-claude-plugins pull
MEMORY_URL=https://memory.onit.systems
MEMORY_TOKEN=<claude token from step 3>

5 First session

Open a project. The agent should recall, then save. Confirm the same fact from the other harness.

Tokens

TokenWhoWhat
adminyou / CLImint/revoke, inbox accept/reject
grok / claudethat harnessrecall, save, wiki, propose — never accept

Plugin

HTTP MCP: POST ${MEMORY_URL}/mcp with Authorization: Bearer <harness token>. No Node server. Tools: recall, save, search, ingest_source, read_page, write_page, lint, inbox_list, inbox_propose. No inbox_accept on MCP.

CLI

memory status
memory token list
memory inbox
memory accept <id>
memory lint
memory import claude --path ~/.claude/projects/<encoded>/memory --dry-run
memory mcp

Cluster / Vault

Namespace harness-memory. Vault KV secret/harness-memory/app (not secret/harness-memory without /app).

PW="$(openssl rand -base64 24)"
vault kv put secret/harness-memory/app \
  POSTGRES_USER=harness \
  POSTGRES_DB=harness \
  POSTGRES_PASSWORD="$PW" \
  DATABASE_URL="postgres://harness:${PW}@postgres:5432/harness?sslmode=disable"

kubectl annotate externalsecret harness-memory-secrets -n harness-memory \
  force-sync="$(date +%s)" --overwrite
kubectl get pods,externalsecret -n harness-memory

Local brew (not shared)

brew services start postgresql@16
createdb memory
brew services start harness-memory
memory init

Do not use this and the cluster as two brains at once.
